## 🌟 Highlight!!!!
This repo is the implementation of "AssistantX: An LLM-Powered Proactive Assistant in Collaborative Human-Populated Environment"**.  

---

## 🛠 Installation

**Environment**
```bash
 pip install -r requirements.txt
```
**Create Environment**
```bash
conda create -n assistantx python=3.10
conda activate assistantx
cd OfficeAssistant
```
**Run our Code**
```bash
python main.py
```
